# Clinical Trial Monitoring Agent — React JS Application

A modern React and TypeScript frontend for an **AI-powered Clinical Trial Monitoring Agent**.

The application provides a structured clinical operations interface for submitting clinical trial site monitoring data to a FastAPI backend and displaying AI-generated monitoring analysis, risk assessment, compliance evaluation, monitoring visit planning, recommendations, and specialized agent summaries.

The solution is designed for **Clinical Research Organizations (CROs)**, sponsors, clinical operations teams, Clinical Research Associates (CRAs), site monitors, and clinical trial quality teams.

---

## Overview

The Clinical Trial Monitoring Agent supports **risk-based clinical trial site monitoring** by analyzing operational, enrollment, compliance, safety, data quality, and monitoring indicators.

The React application sends clinical monitoring data to the backend API:

```text
POST http://127.0.0.1:8000/api/v1/monitoring/analyze
```

The backend analysis is presented through a structured dashboard containing:

* Monitoring analysis summary
* Clinical monitoring metrics
* Site risk assessment
* Compliance assessment
* Monitoring visit planning
* Monitoring recommendations
* Corrective and Preventive Action insights
* Monitoring Agent summary
* Risk Agent summary
* Compliance Agent summary

## TypeScript API Contract Consideration

The frontend and FastAPI response contracts should remain synchronized.

`MonitoringResults.tsx` uses the following response properties:

```typescript
data.message
data.generated_by
data.recommendations
```

Therefore, the `MonitoringResponse` interface should include these fields when they are returned by the FastAPI backend.

Recommended model definition:

```typescript
export interface MonitoringResponse {
  success: boolean;

  message: string;

  generated_by: string;

  study_id: string;

  site_id: string;

  site_name: string;

  monitoring_status: string;

  monitoring_metrics: MonitoringMetrics;

  risk_assessment: RiskAssessment;

  compliance_assessment: ComplianceAssessment;

  monitoring_visit_plan: MonitoringVisitPlan;

  agent_analysis: AgentAnalysis;

  recommendations: MonitoringRecommendation[];
}
```

Keeping the frontend TypeScript interfaces synchronized with FastAPI Pydantic response models prevents TypeScript compilation errors and runtime contract inconsistencies.
